# Rule 16 — Documentation Coherence & Versioning

Rule 06 governs **per-document standards** (what an ADR/README/runbook must
contain). This rule governs **coherence *between* documents**: every fact that
is restated in more than one place has exactly one source of truth, and no
restatement is allowed to drift from it. It is the systemic answer to the
recurring "docs lost the thread" failure mode (stale version strings, mismatched
anti-pattern counts, orphaned ADRs, a `llms.txt` frozen two minor-lines back).

Authority: `AGENTS.md` + ADR-031. Enforcement: `scripts/check_doc_coherence.py`
(deterministic gate) + the `doc-coherence` skill (the agent that *fixes* drift).
Per README §"the agentic surface is not load-bearing": the agent accelerates,
the gate enforces.

## Single source of truth (SSoT) register

| Fact | Canonical owner | Mirrors that MUST track it |
|------|-----------------|-----------------------------|
| Release version | `VERSION` | `CHANGELOG.md` latest released heading, `llms.txt` `> Version:`, README badges |
| Anti-pattern catalogue size | `AGENTS.md` (highest `D-NN` row) | README "N anti-patterns", `llms.txt` `(D-01 to D-NN)`, CLAUDE.md header + skills |
| Agentic surface counts | `agentic/{rules,skills,workflows}/` on disk | CLAUDE.md "N rules + N skills + N workflows", `llms.txt`, AGENTS.md index |
| ADR set + numbering | `docs/decisions/ADR-*.md` files | CHANGELOG entries, ADR index, any "N ADRs" claim |
| Agentic adapters | `agentic/` (ADR-027) | `.claude/ .cursor/ .codex/ .devin/` (generated by `sync_agentic_adapters.py`) |

**Never** restate one of these facts by hand in a mirror without updating the
canonical owner first, then propagating. The gate fails CI when a mirror drifts.

## Versioning policy (SemVer + Keep a Changelog)

- `VERSION` is the single source of truth and MUST equal the most recent
  **released** (dated, non-`[Unreleased]`) heading in `CHANGELOG.md`.
- Every change lands a `CHANGELOG.md` entry under `## [Unreleased]` first; a
  release moves those lines under a new dated `## [vX.Y.Z]` heading and bumps
  `VERSION` in the same commit.
- The active public line is `v0.x` hardening; tags `v1.0.0`–`v1.12.0` are
  immutable historical audit snapshots (see `docs/RELEASING.md`).
- A doc that intentionally tracks a different version (e.g. a spec snapshot)
  MUST carry an explicit `legacy-snapshot` marker so the gate can skip it.

## Change traceability (no lost thread)

Every non-trivial change MUST be relatable end-to-end:

```
decision → ADR-NNN  ⇄  CHANGELOG [Unreleased] entry  ⇄  release vX.Y.Z  ⇄  VERSION
```

- A new **ADR** is referenced from `CHANGELOG.md` (and never silently dropped —
  numbering is immutable; a withdrawn number gets a `Status: Withdrawn`
  tombstone file, see ADR-012).
- A new **rule / skill / workflow** is registered in
  `templates/config/agentic_manifest.yaml`, generated into adapters via
  `sync_agentic_adapters.py`, indexed in `AGENTS.md`, and counted in CLAUDE.md.
- Pattern basis (adopt the *pattern*, not a new dependency): Keep a Changelog +
  SemVer (already in use), towncrier/changesets-style "one fragment per change"
  traceability, release-please/Conventional-Commits-style version↔changelog
  coupling, MADR/Log4brains ADR lifecycle, Vale-style prose consistency,
  Diátaxis doc taxonomy. ADR-031 records why we encode the *coherence contract*
  ourselves rather than adopting any one tool wholesale.

## The cascade map — "if you touch X, update Y"

| If you change… | You MUST also update… |
|----------------|------------------------|
| `VERSION` / cut a release | `CHANGELOG.md` heading, `llms.txt` version, README badges |
| Add/remove an anti-pattern in `AGENTS.md` | README count, `llms.txt` range, CLAUDE.md header + table, rule-audit + debug-ml-inference skills |
| Add/remove a rule, skill, or workflow | `agentic_manifest.yaml`, run `sync_agentic_adapters.py`, CLAUDE.md counts, AGENTS.md index, `llms.txt` |
| Add/withdraw an ADR | `CHANGELOG.md` reference, ADR index, any "N ADRs" claim; withdrawals get a tombstone |
| Edit a canonical `agentic/` body | run `sync_agentic_adapters.py` (CI `--check` enforces adapter parity) |

## Enforcement

```bash
# Deterministic gate (CI-blocking, same family as check_*_drift.py)
python3 scripts/check_doc_coherence.py

# Fix drift with the agent, then re-run the gate
#   → skill: doc-coherence   workflow: /doc-coherence
```

The gate runs five checks: version SSoT (C1), `llms.txt` version (C2),
anti-pattern count (C3), agentic surface counts (C4), ADR traceability /
no-silent-gaps (C5). A failing gate blocks the PR — coherence is a release
invariant, not a suggestion.
