# Devin Context — pointer only

Start with `AGENT_CONTEXT.md`. Everything that applies to every agent
applies to Devin Desktop.

## Devin-specific entry points

- Mirror surface (ADR-027). Canonical bodies live in `agentic/`; `.devin/`
  holds a byte-identical generated copy because Devin Desktop ingests
  directory bodies (it cannot follow pointers). `.devin/` is the preferred
  IDE location and takes precedence per the Cognition FAQ.
- Rules: `.devin/rules/` (15 files, generated from `agentic/rules/`)
- Skills: `.devin/skills/` (16 folders, each with `SKILL.md`)
- Workflows: `.devin/workflows/` (12 files)
- MCP config: consumer responsibility, see
  `~/.codeium/mcp_config.json` (never committed).

## Devin-specific behaviour

- **Never edit `.devin/` by hand** — it is generated. Edit the canonical
  body under `agentic/...`, then run
  `python3 scripts/sync_agentic_adapters.py`.
- Use `AGENTS.md` as the authority for protocol and invariants.
- Consult `templates/config/agentic_manifest.yaml` before editing any
  rule / skill / workflow — its entry must match reality on disk.
- Do not install or configure MCPs without explicit human approval.
- Treat production writes as STOP.
- For code changes, run the narrow verifiers first:
  `python3 scripts/validate_agentic.py --strict` and
  `python3 scripts/validate_agentic_manifest.py --strict`.
